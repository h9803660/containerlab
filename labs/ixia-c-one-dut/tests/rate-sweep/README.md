# レート比較試験スクリプト

このフォルダには、`TEST_REPORT.md` の切り分けで使用したスクリプトを保存している。Git 管理に向けてソースファイルの参照をリポジトリ相対パスにし、Etba の PID を実行時に取得するよう変更した。試験の送信条件と実測結果は変更していない。元の snappi スクリプト、containerlab topology、cEOS 設定は変更していない。

| ファイル | 実施した試験 | 計測内容 |
|---|---|---|
| `ixia_rate_sweep.py` | 1%、2%、5%を各10秒・双方向 UDP で実施 | フローごとの Tx/Rx、cEOS Ethernet1/2 の InDiscards 前後差 |
| `ixia_low_rate_sweep.py` | 0.1%、0.2%、0.5%を同条件で実施 | 上記に加え Etba CPU time 前後差、送信中の Etba とコンテナ CPU サンプル |

どちらもリポジトリ内の `../clab-device-endpoint.py` を読み取り、レート指定だけをメモリ上で置換して実行する。元ファイルへの書き込みはしない。`snappi` を利用できる Python 環境が必要。結果は標準出力の JSON に出力し、実測値は `TEST_REPORT.md` に転記している。

## 実行時の注意

- スクリプト内のソースパス、ixia-c API、cEOS コンテナ名、`ixia_rate_sweep.py` のレート置換文字列は、この検証環境に固定されている。
- 実行すると `api.set_config()` により ixia-c の現在の OTG 設定が置き換わり、プロトコルとトラフィックが開始・停止する。元の snappi 例には `protocol.all.STOP` が含まれる。他の ixia-c 試験が動いていないことを確認してから使用する。
- `ixia_rate_sweep.py` は10%を試験する前に、置換前後が同じことを誤ってエラーと判定する。このため実際に完了したのは1%、2%、5%のみ。**10%の値はこのファイルによる試験結果ではない。**
- `ixia_low_rate_sweep.py` は試験時に Etba の PID を検索する。Etba プロセスが1つでない場合はエラーで停止する。
- どちらのスクリプトも、API エラーやリンク異常が出た場合は残りのレートを停止する。パケット損失自体は比較対象なので停止条件にしていない。

試験時にはリポジトリ外の元スクリプトを使用した。保存版は参照パスと PID 取得だけを変更しており、この保存版自体での再試験はまだ行っていない。
